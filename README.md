# srao189.github.io

Sahar Rao's web portfolio: four rebuilt class websites, shown as journal-style before/after figures. Panel **a** is the graded original, preserved at each repo's `submitted-original` tag. Panel **b** is the revision.

Live: https://srao189.github.io/

- Screenshots are real captures: panel a from a local checkout of each `submitted-original` tag, panel b from the live site, at 1440×900 and 390×844.
- On desktop, scroll pins each figure and wipes from a to b (GSAP ScrollTrigger plus Lenis smooth scroll, self-hosted). On wide screens a range slider compares a and b for every visitor; scroll scrubbing needs a mouse or trackpad and no reduced-motion preference. Phones and no-JS visitors get complete side-by-side panels.
- No build step. Vendor files: GSAP 3.13.0 (GreenSock standard no-charge license), Lenis 1.3.4 (MIT). Font: Schibsted Grotesk (SIL OFL).
- Built with AI assistance (Claude Code; Codex as reviewer).
